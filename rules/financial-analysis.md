# Financial analysis rules

State whether a sentence is an observation, a calculation, a scenario, or an interpretation. Do not add a price, filing, or yield that is not in the evidence. Do not promise a return. Distinguish a FII quota from a CRI and from owning a property.

When the prose names Barsi, Bazin, Buffett, Graham, Baroni, Alden, or Antonopoulos, it is applying `rules/analyst-patterns.md`. The name restates an emitted metric. It does not add a target, a hurdle, a moat, or a portfolio.

`coverage.score` counts received card fields. It is not a grade for buying the asset.
