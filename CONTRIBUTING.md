# Contributing

1. Open an issue or a short design note for behavior changes.
2. Read the matching file in `specs/` and any ADR the change touches.
3. Keep the patch small enough to test.
4. Add or update a unit, contract, or API test. Do not require a paid model call.
5. Run Ruff, Pyright, and pytest.
6. Describe what you ran and what you did not run.

Do not present fixture prices as live quotes in docs or issues.
