# Functional spec

- Resolve equities, crypto ids, and explicit FII tickers.
- Reject an unqualified ticker that ends in 11.
- Fetch prices through the provider registry.
- Calculate return, volatility, drawdown, a short moving average, a historical distribution, and an in-sample buy-and-hold result when the sample is long enough.
- Apply vacancy only to brick FIIs.
- Build bear, base, and bull prices from assumptions.
- Validate provenance, freshness, conflicts, and instruction-like text.
- Persist the request, status, report, evidence, and usage.
- Return Brazilian Portuguese text that does not add facts.
