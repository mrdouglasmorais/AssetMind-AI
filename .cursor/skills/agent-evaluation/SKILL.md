# Agent evaluation

1. Check that every number in the narrative comes from a metric or scenario field.
2. Check that missing and stale data are disclosed.
3. Check that the disclaimer is present and that no return is promised.
4. Confirm provider prose, including instruction-like text, is absent from the narrative.
5. Record the fixtures used. Do not claim a live-model score unless that call was made.
