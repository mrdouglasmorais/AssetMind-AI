# Quantitative analysis

1. Write the formula, units, sampling rule, and limitation next to the function.
2. Truncate the series at `as_of` before using it.
3. Add a test with a hand-computed expected value.
4. Do not describe the result as a probability or a forecast.
5. Keep vacancy, dividend yield, and price ratios on the paths that have the required inputs.
