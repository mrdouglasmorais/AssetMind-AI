# Glossary

| Term | Meaning |
| --- | --- |
| Equity | A B3 stock or unit, such as PETR4. |
| FII | A Brazilian real-estate fund quota, not a CRI and not a direct property. |
| Brick fund | A property fund. Vacancy can apply. |
| Paper fund | A receivables fund. Vacancy does not apply. Credit and indexer risk do. |
| Evidence | One observation with provider, times, metric, value, and quality. |
| Reference price | The latest fresh, non-conflicting close. |
| Scenario | An assumption applied to the reference price. |
