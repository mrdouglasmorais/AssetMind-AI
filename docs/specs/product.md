# Product

AssetMind analyzes a B3 equity, a FII from the brapi list, or a CoinGecko id, and returns a sourced educational report. Search reads those provider lists. Users can create an analysis, read its status, stream stored events, and fetch the report.

The product does not recommend a buy or sell, and it does not execute trades.

Success for the MVP is a reproducible API that can explain where each number came from and what it refused to calculate.
