# Agent contracts

The default orchestrator is an Agno workflow of Python steps: validate, plan, parallel fetch, analyze, verify, report.

Equity, crypto, and real-estate stages are not model agents. They filter assets and call the deterministic engine.

The report composer in the default path is a template. An optional Agno agent may later narrate the same structured object. It receives no web tool and no skill-script tool. If its structured output is invalid, the template remains the report and the error is recorded.

Agno Team is not used. Routing is fully determined by asset class.
