# ADR 0001 — Agno as the orchestrator

Status: accepted

Context: The project needs a visible agent framework with workflow control, without inventing an orchestrator.

Decision: Use Agno 3.1.12 `Workflow`, `Step`, and `Parallel`. Do not add another agent framework.

Alternatives: LangGraph, CrewAI, and a custom state machine alone.

Consequences: Workflow code follows Agno's current constructors. Team is unused because routing is deterministic.
