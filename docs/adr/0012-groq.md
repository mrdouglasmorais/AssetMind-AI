# ADR 0012 — Groq as the LLM provider

Status: accepted

Context: The chat surface needs one model provider. ADR 0004 left OpenRouter as a provisional gateway that the default analysis does not call.

Decision: Groq is the configured provider (`ASSETMIND_LLM_PROVIDER=groq`). The Agent UI analyst uses `agno.models.groq.Groq` when `GROQ_API_KEY` and `ASSETMIND_GROQ_MODEL` are set. The default model id is `openai/gpt-oss-120b`, the default in the installed Agno Groq class. The agent must call the deterministic analysis tool and may repeat only figures from that result. Without a key, the analyst returns that same report directly. OpenRouter stays as an alternate constructor.

Alternatives: Keep the analyst deterministic even when a key is present, or send every turn through OpenRouter.

Consequences: A configured key spends Groq tokens on chat turns. Tests construct the client and do not call Groq. No live Groq call has been measured.
